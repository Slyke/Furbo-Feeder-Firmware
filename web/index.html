Wi-Fi & recovery
A protected setup network appears if the stored Wi-Fi is unavailable for 90 seconds. The setup network is furbo2 / furbo2setup. A 10s rear-button hold requests recovery when the local network manager is installed. It clears saved Wi-Fi and local sign-in credentials; recordings stay on the device.
New Wi-Fi is a trial. Confirm it within five minutes. Rebooting before confirmation restores the last confirmed network.
